# Backtester strategy API (api_version 1)

Generated by `backtest kit` from backtester 0.1.0. Do not edit by hand; regenerate it instead.

This document is the complete contract for writing a strategy. A strategy is one Python file in the `strategies/` folder containing exactly one `Strategy` subclass, plus an optional `test_<file name>.py` with fixture tests. The app validates every file before it runs and reports each problem with its file, line, rule and a fix hint.

## Quick start

Copy this template, rename the class and file, and change the logic.

```python
from backtester import Param, Strategy


class MyStrategy(Strategy):
    api_version = 1
    name = "My strategy"
    description = "Buy a close above the prior N-session high; exit after a fixed number of sessions."
    requires = ["prices"]
    universe = ["SPY", "QQQ", "IWM"]
    params = {
        "lookback": Param(int, default=20, min=5, max=250, description="Sessions in the prior high"),
        "hold": Param(int, default=10, min=1, max=100, description="Sessions to hold each entry"),
        "size": Param(float, default=0.25, min=0.01, max=0.33, description="Fraction of equity per entry"),
    }

    def on_bar(self, ctx):
        # Decided before today's open; the last row is yesterday's close.
        closes = ctx.history("close", self.p.lookback + 1)
        if len(closes) < self.p.lookback + 1:
            return  # not enough history yet
        for ticker in ctx.universe:
            if ctx.position(ticker).qty > 0:
                continue  # already holding; the exit is scheduled
            prior_high = closes[ticker].iloc[:-1].max()
            if closes[ticker].iloc[-1] > prior_high:
                ctx.order(ticker, pct=self.p.size, at="open", exit_after=self.p.hold, tag="breakout")
```

## How a run works

```text
The daily cycle.

For each session t:
  1. Advance the clock: bars through the close of t-1 become visible.
     Positions in securities that stopped trading are closed at their last close.
  2. Queue scheduled exits (``exit_after`` reached) as open orders.
  3. Call ``on_bar(ctx)`` (and ``on_start`` before the first one).
  4. Fill open orders at t's open; check stops/targets against t's high/low;
     fill close orders at t's close.
  5. Mark the portfolio to t's close and record an equity snapshot.
```

- Decisions in `on_bar` are made before the session's open, using bars through the previous close. Today's bar is never visible.
- `at="open"` orders fill at today's open; `at="close"` orders fill at today's close.
- Prices are adjusted for splits and dividends.
- `pct`, `value` and `target_weights` orders are converted to shares at the fill price.
- Within a batch, sells fill before buys. A buy larger than available cash is resized to fit (or rejected, if the run is set that way).
- Orders last one session. An order for a ticker with no bar that session is skipped and logged.
- Long-only: sells are capped at the position. Whole shares unless the run enables fractional shares.

## The Strategy class

```python
class Strategy
```

Base class for strategies. A strategy file contains exactly one subclass.

Required class attributes:
    api_version: Strategy contract version. Only ``1`` is supported.
    name: Short name shown in the strategy library.
    description: One sentence on what the strategy does.
    requires: Data the engine must load, by name: ``"prices"`` plus any
        feeds, e.g. ``["prices", "my_events", "market_cap"]``.
    universe: Default tickers: a list such as ``["SPY", "QQQ"]``, the
        name of a ticker list in ``data/universes/<name>.txt``, or
        ``"from_feed:<name>"`` for every ticker a feed has mentioned so far
        (the feed must be in ``requires``).
    params: Dict of ``Param`` declarations. Resolved values are available
        as ``self.p.<name>``.

Optional class attributes:
    hypothesis: What the strategy tests, in one or two plain sentences:
        the idea with its specifics (tickers, signal, hold) and why it
        should work. Shown under the strategy's name on the Results page.

Hooks (all receive the point-in-time context ``ctx``):
    on_start(ctx): Once, before the first ``on_bar``.
    on_bar(ctx): Once per session, before the open. Place orders here.
    on_fill(ctx, fill): After each fill. Orders placed here fill next session.
    on_end(ctx): Once, after the last session is marked.

The strategy must touch the market only through ``ctx``, and must not use
randomness other than ``ctx.rng``.

Supported `api_version` values: 1. Built-in names for `requires`: `market_cap`, `prices`, `shares_outstanding`, plus any feed added under `data/feeds/` or `feeds/` (see Feeds below).

## Param

A typed strategy parameter. Each one becomes a run-config field and a UI field.

Args:
    type: One of ``int``, ``float``, ``bool`` or ``str``.
    default: Value used when the run config does not override it. Must be
        inside ``[min, max]`` and in ``choices`` when those are given.
    min: Smallest allowed value (numbers only), inclusive.
    max: Largest allowed value (numbers only), inclusive.
    choices: Allowed values, for a fixed set of options.
    description: One line shown next to the field in the UI.

## ctx: the strategy's view of the market and the account

Point-in-time view of the market and the account, passed to every hook.

### `ctx.today` (property)

Current session date. Decisions are made before this session's open.

### `ctx.universe` (property)

Tickers in scope this session, in config order. For a ``from_feed``
universe: every ticker the feed has mentioned in records visible so far,
in order of first mention.

### `ctx.benchmark` (property)

The run's benchmark ticker (``SPY`` unless the run sets another).

Its prices are always loaded, so a strategy may trade it even when it
is not in ``ctx.universe`` (for example, to keep idle cash in the
index it is judged against) and read it with
``ctx.history(field, n, [ctx.benchmark])``.

### `ctx.is_first_session_of(period: str) -> bool`

True if today is the first trading session of its ``"week"``,
``"month"``, ``"quarter"`` or ``"year"``.

Compares against the previous NYSE session, so a run starting mid-month
does not count its first session as the first of the month.

### `ctx.history(field: str, n: int, tickers: list[str] | None = None) -> pd.DataFrame`

Last ``n`` completed bars of one field as a DataFrame.

Args:
    field: ``"open"``, ``"high"``, ``"low"``, ``"close"``, ``"volume"``
        or ``"dollar_volume"``. Prices are split- and dividend-adjusted.
    n: Number of sessions. Fewer rows come back if history is shorter.
    tickers: Columns to return; defaults to ``ctx.universe``.

Returns:
    Rows are sessions (oldest first, the last row is the previous
    session), columns are tickers, NaN where a ticker had no bar. The
    frame is a copy; changing it does not affect later calls.

### `ctx.price(ticker: str) -> float`

Last completed close for ``ticker`` (the previous session's, or the
most recent before it if the ticker did not trade). NaN if none.

### `ctx.bar(ticker: str, date) -> Bar | None`

The completed bar for ``ticker`` on ``date``, or None if it had no bar.

Raises ``LookaheadError`` if ``date`` is today or later.

### `ctx.events(name: str) -> list`

Records from event feed ``name`` that became visible since the last session.

A record is visible on session t if its ``available_at`` is before
09:30 ET on t, so acting on it ``at="open"`` trades at t's open. Each
record is returned on exactly one session. The feed must be in
``requires``.

Returns:
    A list of ``Event`` objects in ``available_at`` order (empty if
    none). Use ``e.id`` as the order ``tag`` (or in ``ctx.reject``) so
    the signal audit can show what happened to each event.

### `ctx.ref(ticker: str, field: str, default=nan)`

Latest value of a reference field for ``ticker``, as known before today's open.

``field`` is a column of a reference feed in ``requires``, e.g.
``"market_cap"``, ``"shares_outstanding"`` or ``"sector"``; write
``"feed.column"`` if two feeds share a column name. ``market_cap`` is
the last raw (unadjusted) close times the latest shares outstanding.

Returns:
    The value, or ``default`` (NaN) if nothing is known yet.

### `ctx.position(ticker: str) -> Position`

Current holding in ``ticker`` (``qty`` is 0 if none).

### `ctx.positions` (property)

All current holdings, keyed by ticker.

### `ctx.cash` (property)

Cash available.

### `ctx.equity` (property)

Cash plus holdings valued at the last completed close.

### `ctx.order(ticker: str, shares: float | None = None, pct: float | None = None, value: float | None = None, at: str = 'open', stop: float | None = None, target: float | None = None, exit_after: int | None = None, tag: str | None = None) -> int`

Queue an order. Give exactly one of ``shares``, ``pct`` or ``value``.

Args:
    ticker: Ticker to trade.
    shares: Fixed share count. Negative sells.
    pct: Fraction of equity, e.g. ``0.05`` for 5%. Negative sells.
        Shares are computed at fill time from the fill price.
    value: Dollar amount. Negative sells. Shares computed at fill time.
    at: ``"open"`` fills at today's open; ``"close"`` at today's close.
    stop: Exit if the price trades at or below this level (adjusted terms).
    target: Exit if the price trades at or above this level.
    exit_after: Exit at the open this many trading sessions after entry.
    tag: Free text kept on the order, fill and trade (e.g. an event id).

Returns:
    The order id.

Long-only in V1: a sell larger than the position is clipped to it.
``stop``, ``target`` and ``exit_after`` apply to buys and create a
separate trade record.

### `ctx.target_weights(weights: dict[str, float], at: str = 'open') -> list[int]`

Rebalance so each ticker is ``weight`` x equity; close holdings not listed.

Weights must be >= 0 and sum to at most 1. Share counts are computed at
fill time from the fill price. Returns the order ids.

### `ctx.close(ticker: str, at: str = 'open', tag: str | None = None) -> int`

Exit the whole position in ``ticker`` at today's open or close. Returns the order id.

### `ctx.reject(subject, reason: str) -> None`

Record that a candidate was considered and skipped, and why.

``subject`` is a ticker or an object with a ``ticker`` attribute (and
optionally ``id``). Rejections appear in the signal audit.

### `ctx.log(msg: str, **fields) -> None`

Write a structured line to the run's log.

`ctx.state` is a dict that persists across sessions. `ctx.rng` is a seeded `numpy.random.Generator`, the only allowed source of randomness.

## Feeds: events and reference data

Prices are built in. Anything else arrives as a **feed**, named in `requires`:

- **Event feeds** hold records that appear at a moment (filings, earnings, your own signals). Read them with `ctx.events(name)`. Each record is delivered once, on the first session whose 09:30 ET open comes after its `available_at`, so acting `at="open"` trades that session's open. A record published after the open, or with a date but no time, trades the next session.
- **Reference feeds** hold a per-ticker value that changes over time (sector, shares outstanding). Read the latest value known before today's open with `ctx.ref(ticker, field)`.
- Built-in: `shares_outstanding` (Yahoo, as reported) and `market_cap` (last raw close x the latest shares outstanding).
- `universe = "from_feed:<name>"` makes the universe every ticker the feed has mentioned in records visible so far. It grows during the run and never includes tickers mentioned later.
- Tag each order with the event's id (`tag=e.id`) and pass the event to `ctx.reject(e, reason)` when skipping it. The signal audit then shows what happened to every event.
- An event for a ticker with no price data is skipped and logged; the skip rate is a headline metric.

```python
class EventHold(Strategy):
    requires = ["prices", "my_events", "market_cap"]
    universe = "from_feed:my_events"
    params = {"hold_days": Param(int, default=30, min=1, max=250), "cap_max": Param(float, default=2e9, min=0)}

    def on_bar(self, ctx):
        for e in ctx.events("my_events"):
            if ctx.ref(e.ticker, "market_cap") > self.p.cap_max:
                ctx.reject(e, "above cap_max")
                continue
            ctx.order(e.ticker, pct=0.05, at="open", exit_after=self.p.hold_days, tag=e.id)
```

### `Event`

One record from an event feed, as returned by ``ctx.events``.

Attributes:
    id: Stable record id (use it as an order ``tag`` and in ``ctx.reject``,
        so the signal audit can link the event to what happened to it).
    ticker: Ticker the record is about.
    available_at: When the record became knowable (UTC timestamp).
    entity_id: Optional entity identifier (CIK, FIGI, ...), or None.
    feed: Name of the feed.
    data: Every value column, as a dict. Each is also an attribute:
        ``e.value`` or ``e["value"]``.

### Adding a feed from a file

Drop CSV or Parquet files into `data/feeds/<name>/` next to a `feed.yaml`. No code is needed. Every record needs a ticker and an `available_at` time: when the information became knowable, not when the underlying thing happened.

```yaml
kind: event                  # or reference
description: Insider purchases from my screener
ticker_column: symbol        # default: ticker
time_column: filed_at        # default: available_at
timezone: America/New_York   # for timestamps without a UTC offset
default_time: "18:00"        # for date-only timestamps (default 18:00)
entity_column: cik           # optional
id_column: filing_id         # optional; otherwise ids are derived from each record
columns:                     # optional; default is every other column
  value: float
  title: str
```

### Adding a feed as a Python plug-in

For data that must be fetched or derived, put one `Feed` subclass in a `.py` file in `feeds/`. Plug-ins are not strategies: the strategy rules above do not apply to them.

Base class for Python plug-in feeds: data that must be fetched or derived.

Put a subclass in a ``.py`` file in the ``feeds/`` folder (one per file).

Class attributes:
    name: Feed name, used in a strategy's ``requires``.
    kind: ``"event"`` (records that appear at a moment, read with
        ``ctx.events``) or ``"reference"`` (a per-ticker value that changes
        over time, read with ``ctx.ref``).
    description: One line on what the feed holds.
    columns: Value columns and their types, e.g. ``{"value": float}``.
    timezone: Time zone for ``available_at`` values without an offset.
        Leave as None if every timestamp carries its own offset.
    default_time: Time of day given to date-only ``available_at`` values,
        in ``timezone`` (or US/Eastern). The default is after the close.

Example:
    ``class Ratings(Feed): name = "ratings"; kind = "event"; ...``

`fetch(start: pd.Timestamp | None, end: pd.Timestamp | None, tickers: list[str] | None = None) -> pd.DataFrame`: Return records with ``available_at`` between ``start`` and ``end``.

The frame must have ``ticker`` and ``available_at`` columns plus the
declared ``columns``; ``entity_id`` and ``id`` are optional. ``tickers``
is a hint (the run's tickers, when known); returning more is fine.

Every feed is checked when it is loaded: required columns present, timestamps with a time zone, none in the future, duplicates dropped with a warning, and tickers without cached prices counted. Check feeds with `backtest feeds`.

## Records

### `Position`

A current holding.

Attributes:
    ticker: Ticker held.
    qty: Shares held (positive = long). 0 if not held.
    avg_price: Average entry price of the shares still held.
    market_value: ``qty`` x the last completed close.

### `Fill`

A completed fill, passed to ``on_fill``.

Attributes:
    date: Session the fill happened on.
    ticker: Ticker filled.
    qty: Signed shares: positive bought, negative sold.
    price: Fill price per share, after slippage (adjusted-price terms).
    commission: Commission paid on this fill.
    order_id: Id returned when the order was placed.
    at: ``"open"``, ``"close"`` or ``"intraday"`` (stop/target fills).
    reason: ``"entry"`` for buys; for sells the exit reason
        (``"sell"``, ``"rebalance"``, ``"close"``, ``"exit_after"``,
        ``"stop"``, ``"target"``, ``"stopped_trading"``).
    tag: Tag given when the order was placed, if any.

### `Bar`

One completed daily bar, returned by ``ctx.bar``.

Attributes:
    date: Session date.
    open, high, low, close: Prices, adjusted for splits and dividends.
    volume: Shares traded, adjusted for splits.

## Errors

- `LookaheadError`: the strategy asked for data that was not yet knowable (today or later).
- `OrderError`: an order's arguments are invalid (the message says which).
- `StrategyError`: the file breaks the strategy contract.
- `ConfigError`: a run setting or parameter value is invalid.

## Rules for strategy files

- Imports: only `numpy`, `pandas`, `math`, `statistics`, `datetime`, `dataclasses`, `typing`, and `from backtester import ...` (for example `from backtester import Param, Strategy`). `numpy.random` is not allowed.
- Banned built-ins: `__import__()`, `breakpoint()`, `compile()`, `delattr()`, `eval()`, `exec()`, `exit()`, `getattr()`, `globals()`, `input()`, `locals()`, `open()`, `quit()`, `setattr()`, `vars()`.
- No file access: no `pandas.read_*`, no `numpy.DataSource`, `numpy.fromfile`, `numpy.genfromtxt`, `numpy.load`, `numpy.loadtxt`, `numpy.memmap`, `numpy.save`, `numpy.savetxt`, `numpy.savez`, `numpy.savez_compressed`, and no `.to_clipboard()`, `.to_csv()`, `.to_excel()`, `.to_feather()`, `.to_hdf()`, `.to_json()`, `.to_orc()`, `.to_parquet()`, `.to_pickle()`, `.to_sql()`, `.to_stata()`, `.tofile()`.
- No wall clock: no `.now()`, `.today()`, `.utcnow()`. Use `ctx.today`.
- No randomness except `ctx.rng`.
- No private attributes: nothing that starts with `_`, except your own `self._name` attributes and `super().__init__`. Dunder attributes (`__class__`, `__dict__`, ...) are not allowed.
- Read the market and the account only through `ctx`. Keep state in `ctx.state` or on `self`.

## Validation

Every strategy file goes through these stages in order. Validation stops at the first stage that fails.

| Stage | Checks |
| --- | --- |
| static | Parses; exactly one Strategy subclass; supported api_version; imports on the allowlist; no file, network, subprocess, eval, clock or unseeded-random use; no private attribute access |
| declarations | Imports cleanly; name and description present; every param typed with a default inside its range; requires lists only known feeds; universe resolves; on_bar implemented |
| tests | Runs the strategy's own test_<name>.py fixture tests, if present |
| dry run | 60 sessions on up to 5 tickers from cached data; no exceptions; every order is for a ticker in the universe |
| determinism | Dry run again with a different hash seed; output hashes must match |

A failing stage produces a report like this:

```text
Validation FAILED: my_strategy.py
Stage 1 of 5 (static) failed with 1 issue.

  static        failed
  declarations  not run
  tests         not run
  dry run       not run
  determinism   not run

[1] my_strategy.py:2  import-not-allowed
    Code:  import requests
    Error: module `requests` is not on the import allowlist
    Fix:   Remove it. Strategy files may import only numpy, pandas, ...
```

Validate from the command line with `backtest validate strategies/my_strategy.py`, or on the Strategies page of the app.

## Fixture testing

Put tests in `test_<strategy file name>.py` next to the strategy. They run with pytest during validation. A fixture is a tiny synthetic market, so a test can check the logic exactly ("a breakout on session 30 buys at session 31's open").

### `make_fixture(prices: dict, events: dict | None = None, refs: dict | None = None, start='2024-01-02', volume: float = 1000000.0) -> Fixture`

Build a tiny synthetic market for testing a strategy's logic.

Args:
    prices: Ticker -> prices. Either a list of closes (each bar is flat:
        open = high = low = close), or a DataFrame with ``open``, ``high``,
        ``low``, ``close`` and optionally ``volume`` columns, one row per
        session. A close of ``None`` or NaN means the ticker has no bar that
        session. Every ticker needs the same number of sessions.
    events: Event feeds: feed name -> records, each record a dict (or a
        DataFrame row) with ``ticker``, ``available_at`` and any value
        columns, e.g. ``{"filings": [{"ticker": "AAA", "available_at":
        "2024-01-05 17:00", "value": 2.5}]}``. Times without an offset are
        US/Eastern; a date alone means 18:00 (after the close).
    refs: Reference feeds, in the same form, e.g. ``{"shares_outstanding":
        [{"ticker": "AAA", "available_at": "2024-01-02", "shares_outstanding": 1e6}]}``.
        Supplying ``shares_outstanding`` makes ``market_cap`` work too.
    start: Date of session 0, an NYSE session. Later sessions follow the
        NYSE calendar.
    volume: Daily volume for bars built from a list of closes.

Returns:
    A ``Fixture``. ``fixture.sessions[k]`` is the date of session ``k``.

### `run_on_fixture(strategy, fixture: Fixture, params: dict | None = None, start=None, end=None, universe: list | None = None, **settings) -> FixtureResult`

Run a strategy on a fixture and return what it did.

Args:
    strategy: A Strategy subclass, or the path to a strategy file.
    fixture: From ``make_fixture``.
    params: Parameter overrides, e.g. ``{"lookback": 20}``.
    start: First session to trade, as a session number or a date (default
        0). Earlier sessions are visible to the strategy as history.
    end: Last session to trade, as a session number or a date (default: the
        last session).
    universe: Tickers in scope (default: every fixture ticker, or the
        strategy's own ``from_feed`` universe if it has one).
    **settings: Any other run setting, e.g. ``initial_capital=10_000``,
        ``slippage_bps=5`` or ``fractional_shares=True``.

Returns:
    A ``FixtureResult``.

### `FixtureResult`

What a strategy did on a fixture, returned by ``run_on_fixture``.

Every frame starts with a ``session`` column: the fixture session number
(0-based) of the row's date, so a test can check "a buy on session 31".

Attributes:
    orders: Orders the strategy placed: ``session``, ``date`` (the session
        the order was placed for), ``ticker``, ``kind`` (``order``,
        ``target_weights`` or ``close``), ``shares``, ``pct``, ``value``,
        ``weight``, ``at``, ``stop``, ``target``, ``exit_after``, ``tag``,
        ``status`` (``filled``, ``resized``, ``rejected``, ``skipped``,
        ``no_change`` or ``cancelled``), ``filled_qty``, ``fill_price``,
        ``message``.
    rejects: Candidates skipped with ``ctx.reject``: ``session``, ``date``,
        ``ticker``, ``reason``, ``tag``.
    fills: Every fill, including engine exits (stops, targets, ``exit_after``):
        ``session``, ``date``, ``ticker``, ``qty`` (negative = sold),
        ``price``, ``commission``, ``at``, ``reason``, ``tag``.
    trades: Trade records (``session`` is the entry session):
        ``entry_date``, ``entry_price``, ``exit_date``, ``exit_price``,
        ``shares``, ``pnl``, ``return``, ``sessions_held``, ``exit_reason``,
        ``tag``, ``is_open``.
    equity: Daily ``equity``, ``cash``, ``positions_value`` and ``exposure``.
    signals: The full signal audit: every feed event delivered to the
        strategy (``decision`` "event", with ``feed``, ``event_id`` and an
        ``outcome``: the order status, "rejected" or "no action"), every
        order and every reject.
    log: Run log lines, including ``ctx.log`` output.

Example tests for the template:

```python
from my_strategy import MyStrategy

from backtester.testing import make_fixture, run_on_fixture


def test_buys_at_the_open_after_a_breakout():
    # 30 flat sessions, then session 30 closes above the prior 20-session high.
    fx = make_fixture(prices={"AAA": [100.0] * 30 + [105.0] * 6, "BBB": [50.0] * 36})
    result = run_on_fixture(MyStrategy, fx)
    assert result.orders["ticker"].tolist() == ["AAA"]
    assert result.orders["session"].tolist() == [31]  # decided before session 31's open
    assert result.orders["status"].tolist() == ["filled"]


def test_exits_after_the_hold_period():
    fx = make_fixture(prices={"AAA": [100.0] * 30 + [105.0] * 20})
    result = run_on_fixture(MyStrategy, fx, params={"hold": 5})
    trade = result.trades.iloc[0]
    assert trade["exit_reason"] == "exit_after"
    assert trade["sessions_held"] == 5
```

### `strategies/buy_and_hold.py`

```python
from backtester import Strategy


class BuyAndHold(Strategy):
    api_version = 1
    name = "Buy and hold"
    description = "Buy the universe in equal weights at the first open and hold to the end."
    hypothesis = ("The baseline: what you earn by buying the tickers in equal weights on day one and never "
                  "trading again. Other strategies have to beat this to be worth the effort.")
    requires = ["prices"]
    universe = ["SPY"]
    params = {}

    def on_bar(self, ctx):
        # Retry each session until the position exists (e.g. if a ticker has
        # no bar on the first session).
        if ctx.positions:
            return
        weight = 1 / len(ctx.universe)
        ctx.target_weights({t: weight for t in ctx.universe}, at="open")
```

### `strategies/momentum_rotation.py`

```python
from backtester import Param, Strategy


class MomentumRotation(Strategy):
    api_version = 1
    name = "Momentum rotation"
    description = "Hold the top N tickers by trailing return; rebalance monthly."
    hypothesis = ("Worked example: do recent winners keep winning? Each month, holds the 2 of SPY, QQQ, IWM, "
                  "EFA, TLT and GLD with the best 6-month return, in equal weights.")
    requires = ["prices"]
    universe = ["SPY", "QQQ", "IWM", "EFA", "TLT", "GLD"]
    params = {
        "lookback": Param(int, default=126, min=20, max=252),
        "top_n": Param(int, default=2, min=1, max=6),
    }

    def on_bar(self, ctx):
        if not ctx.is_first_session_of("month"):
            return
        closes = ctx.history("close", self.p.lookback + 1)
        rets = closes.iloc[-1] / closes.iloc[0] - 1
        picks = rets.nlargest(self.p.top_n).index
        ctx.target_weights({t: 1 / self.p.top_n for t in picks}, at="open")
```

```python
from momentum_rotation import MomentumRotation

from backtester.testing import make_fixture, run_on_fixture

N = 60  # sessions: 2024-01-02 through late March


def leader_then_laggard():
    """A rises through session 25 and then falls; B is flat until session 25 and then rises."""
    a = [100 * 1.01 ** min(k, 25) * 0.99 ** max(k - 25, 0) for k in range(N)]
    b = [100 * 1.01 ** max(k - 25, 0) for k in range(N)]
    return make_fixture(prices={"A": a, "B": b, "FLAT": [100.0] * N})


def test_rebalances_only_on_the_first_session_of_each_month():
    fx = leader_then_laggard()
    result = run_on_fixture(MomentumRotation, fx, params={"lookback": 20, "top_n": 1}, start=1)
    s = fx.sessions
    first_of_month = {k for k in range(1, N) if s[k].month != s[k - 1].month}
    assert set(result.orders["session"]) <= first_of_month


def test_holds_the_leader_then_rotates_when_leadership_changes():
    fx = leader_then_laggard()
    result = run_on_fixture(MomentumRotation, fx, params={"lookback": 20, "top_n": 1}, start=1)
    trades = result.trades
    # February: A had the best trailing return, so it is bought.
    a = trades[trades["ticker"] == "A"].iloc[0]
    assert a["entry_date"].month == 2
    # March: B now leads, so A is sold in the rebalance and B is held to the end.
    assert a["exit_reason"] == "rebalance"
    b = trades[trades["ticker"] == "B"].iloc[0]
    assert b["entry_date"] == a["exit_date"]
    assert bool(b["is_open"])
    assert "FLAT" not in set(trades["ticker"])
```

### `strategies/event_hold.py`

```python
from backtester import Param, Strategy


class EventHold(Strategy):
    api_version = 1
    name = "Event hold"
    description = "Buy at the open after a qualifying signal; hold N sessions."
    hypothesis = ("Worked example: do stocks rise after a signal in the sample feed? Buys 20% of equity at the "
                  "next open when a signal scores 0.5 or more, and sells 10 sessions later.")
    requires = ["prices", "sample_signals"]
    universe = "from_feed:sample_signals"
    params = {
        "hold_days": Param(int, default=10, min=1, max=250, description="Sessions to hold each position"),
        "min_score": Param(float, default=0.5, min=0.0, max=1.0, description="Skip signals scoring below this"),
        "size": Param(float, default=0.2, min=0.01, max=1.0, description="Fraction of equity per position"),
    }

    def on_bar(self, ctx):
        for e in ctx.events("sample_signals"):
            if e.score < self.p.min_score:
                ctx.reject(e, "score below min_score")
                continue
            if ctx.position(e.ticker).qty > 0:
                ctx.reject(e, "already holding")
                continue
            ctx.order(e.ticker, pct=self.p.size, at="open", exit_after=self.p.hold_days, tag=e.id)
```

from event_hold import EventHold

from backtester.testing import make_fixture, run_on_fixture

# Sessions start Tue 2024-01-02: session 1 is Wed 01-03, session 2 is Thu 01-04.
PRICES = {"AAA": [10.0] * 30, "BBB": [20.0] * 30}

    return {"sample_signals": [dict(zip(("ticker", "available_at", "score", "note"), r)) for r in records]}


def test_a_signal_after_the_close_buys_at_the_next_open():
